# 踩坑清单：12 个实测踩过的坑

> 每一条都对应真实的时间损失或误判。按「症状 → 原因 → 正确做法」排列。

---

## 坑 1：里程抓到的是「续航」

**症状**：180 条数据里 20+ 条里程判错，一台 2000 公里的车被判成 60 公里。

**原因**：标题写「续航 60 公里，总里程 2000 公里」。正则先命中「60公里」。

**正确做法**：提取里程前，先检查匹配位置前面 10 个字符有没有 `续航|能跑|跑得到|满把|满电|理论`，有就跳过这个匹配。

```js
const before = t.slice(Math.max(0, m.index - 10), m.index);
if (/续航|能跑|跑得到|满把|满电|理论/.test(before)) continue;
```

## 坑 2：`26年` 被解析成 2200 年前

**症状**：所有 2026 年激活的车全被过滤掉，A 级车一台都没有。

**原因**：正则只捕获两位数字，`26` → `new Date(26)` → 公元 26 年 → 车龄 24000 个月。

**正确做法**：两位数年份补 2000，且加合法性校验：

```js
let y = +m[1]; if (y < 100) y += 2000;
if (y < 2023 || y > 2027) continue;   // 脏数据兜底
```

第二条校验还顺带挡掉了「mk2 25年」被拼成 `225` 的脏数据。

## 坑 3：「总里程5 159公里」被读成 159

**症状**：里程数字被截断。

**原因**：闲鱼标题里数字中间可能有空格（防屏蔽），正则匹配到后半段。

**正确做法**：归一化时先把数字之间的空格去掉。

```js
t.replace(/(\d)\s+(\d)/g, '$1$2')
```

---

## 坑 4：品牌黑名单误杀 20%

**症状**：明确写着九号的整车被剔除了。

**原因**：卖家写「支持换雅迪」「比小牛好骑」「同价位吊打台铃」—— 这是九号车在**对比**。按「出现其他品牌名就排除」来写，误杀率极高。

**正确做法**：**只做白名单，不做黑名单。** 命中目标品牌名或型号词就收，其他品牌名只用于排障提示，不参与判定。

---

## 坑 5：配件词一刀切，误杀 20%

**症状**：180 条里 36 条被误判成配件。

**原因**：「整车配件齐全」「原装配件都在」「改了一些配件」全是整车描述。关键词 `配件` 一命中就剔，全死。

**正确做法**：配件判定必须叠加「**是否具备车辆主体特征**」：

```js
const accPart = ACC_PART.test(t) && !VEHICLE_SIGNAL.test(t);
```

`VEHICLE_SIGNAL` 包含：公里 / km / 空车 / 过户 / 上牌 / 车牌 / 成色 / 车况 / 激活 / 里程 /
整车 / 自提 / 骑行 / 跑了 / 一手车 / 手续 / 合格证 / 钥匙 …

「配件」二字**不能单独作为强信号**，必须搭配「适用/同款/兼容」这类明确指向。

---

## 坑 6：`--region` 文本匹配把结果全杀

**症状**：加了 `--region "深圳"` 之后，一条结果都没有。

**原因**：**未登录时闲鱼的 `area` 字段恒为空**。本地只能拿标题做匹配，而绝大多数标题不写城市名。

**正确做法**：用 `--zone`，走闲鱼官方的「区域」筛选浮层（`.ant-popover`），**服务端过滤，不依赖登录**。

---

## 坑 7：`mk2` 撞三种车

**症状**：抓「机械师MK2」，结果混进 E80C MK2（电摩）、猎户座 DZ110P MK2、Mz330 门店贴。

**原因**：`mk2` 是九号多个车系共用的代际后缀。

**正确做法**：判 MK2 前先过「型号闸门」：

1. 必须有 `机械师|mmax` 承载
2. 标题前 18 个字符不能是别的车系主语

---

## 坑 8：别的型号抢先出现

**症状**：「九号机械师90 450拉3000w…接置换机械师mk2」被算成 MK2。

**原因**：这是 MMAX90 的改装贴，末尾只是提了一句"接置换 mk2"。

**正确做法**：比较位置 —— `OTHER_MMAX` 首次出现位置**早于** `mk2` → 判给那台车。

---

## 坑 9：原厂电池被当成改装，价格被当成电池容量

**症状**：一堆原装车被判成中改；一台 ¥7699 的车被判成「76V99Ah 大单体」。

**原因**：
- `4825 / 4830 / 48V30Ah / 48-30` 是九号原厂标配，被 `48V\d+Ah` 规则命中
- `7699` 是价格，被 `(\d{2})(\d{2})` 拆成 76V99Ah

**正确做法**：
- 判改装前先 `stripStock()` 摘掉原厂规格 `48\s*[-v]?\s*(25|30)\s*(a|ah|安)`
- 四位简写必须加 lookahead：`(?:72|76|80|84)(?:v)?([2-9]\d)(?=电池|锂电|安)`

---

## 坑 10：否定句反向判定

**症状**：
- 「没改装控制器」被判成改装
- 「不带电池」被判成带电池
- 「没有牌照」被判成带牌

**原因**：正则只匹配关键词，不管语义否定。

**正确做法**：前置排除。

```js
const NOBAT   = /空车|不带电池|不含电池|无电池|没电池/;
const NOPLATE = /没有牌照|无牌照|不带牌|无牌|没牌|不带证|不上牌/;

noBat: NOBAT.test(t),
plate: !NOPLATE.test(t) && /带牌|有牌|上牌|过户|牌照|绿牌|白牌/.test(t),
```

---

## 坑 11：换轮胎被当成改装

**症状**：刚换过轮胎的正常保养车被判成改装车。

**原因**：`换轮胎` 命中改装动词。

**正确做法**：
- 换轮胎、换刹车片 = **保养**，不是改装
- 「其它全原」常与「改了上泵」同时出现 → `STOCK_ASSERT` 与 `MOD_VERB` 冲突时，**以后者为准**

---

## 坑 12：¥1 标价把行情带偏

**症状**：某型号价格中位数变成 ¥1。

**原因**：改装圈行规 —— 标 1 元强制私聊，真实成交 1.5–2.5 万。

**正确做法**：`价格 < ¥300` 一律剔除（不做中位数计算）。同时剔「租/分期/首付/押金/回收」噪音。

## 附：工程层面的坑（跟判断无关，但会让你跑不起来）

| 坑 | 现象 | 解法 |
|---|---|---|
| `better-sqlite3` 在 Windows 编译失败 | 缺 VS C++ 构建工具 | 改用 Node 内置 `node:sqlite`（v22.5+），零编译 |
| PowerShell 脚本含中文 | 被按 GBK 解析，报「字符串缺少终止符」 | ps1 内容保持**纯 ASCII** |
| headless Chrome | 被拦「非法访问」 | 必须**非 headless** + CDP Input |
| 目录层级错 | DB 写到 `skills/data/` 而不是 `skills/xianyu-monitor/data/` | 用 `path.join(__dirname, '..', 'data')` |
| Chrome 被会话结束带走 | 下次跑报「无法连接 Chrome」 | `ensureChrome()` 自愈：检测不到就 spawn detached + 轮询 |
| 闲鱼参数栏 innerText 是竖排 | `品\n牌\n：\n九号电动`，正则匹配不到 | 遍历 `li` 取 `textContent` 归一化，别用 `品牌：xxx` |
