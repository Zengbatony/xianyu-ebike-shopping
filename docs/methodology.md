# 方法论：怎么判断一台二手电动车值不值

> 这份文档不讲代码，只讲判断。代码可以重写，判断错了就是几千块。

---

## 一、先想清楚：你到底在买什么

二手电动车拆开是四部分：

| 部件 | 占成本 | 会不会坏 | 能不能验 |
|---|---|---|---|
| 电池 | **30–50%** | 会，且衰减不可逆 | **能（BMS 循环数）** |
| 电机 | 10–15% | 几乎不坏 | 难 |
| 车架/减震 | 15–20% | 会（异响、漏油） | 能（试骑） |
| 控制器/线束 | 10% | 会（进水、烧管） | 难 |

**唯一既能大幅折价、又能客观验证的，就是电池。** 所以整个估值体系应该锚在电池上，而不是年份、外观、配置。

这也是为什么：一台 2025 年激活、循环 109 次的车，比一台 2024 年激活、循环 530 次的车值钱得多，哪怕后者"年款更新""配置更高"。

---

## 二、三个锚点，按可信度排序

### 锚点 1：电池循环次数（最可信）

BMS 记录充放电循环，**改不了**。让卖家截 APP 车辆页。

| 循环数 | 状态 | 估值含义 |
|---|---|---|
| 0–50 | 几乎全新 | 可给到新车价 75–85% |
| 50–200 | 良好 | 主力区间，正常折价 |
| 200–400 | 中度衰减 | 续航打 8 折，要压价 |
| 400–600 | 明显衰减 | 电池接近该换，按"半台车"砍 |
| >600 | 报废边缘 | 只按车架残值算 |

### 锚点 2：激活日期（次可信）

能对上 APP、能对上发票、能对上保修卡，三者一致才采信。

**「24款/25款/26款」不是车龄，是车型版本。** 实测同一标签下车龄能差 15 个月。

### 锚点 3：仪表里程（最不可信）

能改，而且改起来很便宜。**必须交叉验证**（见第三节）。

---

## 三、交叉验证：一个除法戳穿调表

48V30Ah 锂电实际单次满放续航 55–70 km（标称 95 km 是理想工况）。

```
单次循环里程 = 总里程 ÷ 循环次数
```

| 算式 | 结果 | 判断 |
|---|---|---|
| 4700 ÷ 74 | 63.5 km/次 | ✅ 正常自洽 |
| 4000 ÷ 109 | 36.7 km/次 | ✅ 偏短但合理（短途通勤，每次骑不远） |
| 2000 ÷ 200 | 10.0 km/次 | ❌ **物理上不可能** |
| 14000 ÷ 530 | 26.4 km/次 | ✅ 合理（长年短途） |

**判断边界：**
- 15–75 km/次 → 合理
- < 10 km/次 → 必是调表（除非有特殊使用场景，比如外卖骑手频繁小段充电）
- > 80 km/次 → 里程被改小了，或者电池容量更大

> 一个反直觉的点：**单次里程偏短不一定是坏事**。30–40 km/次说明是短途通勤，
> 电池在高 SOC 区间循环，衰减反而慢。真正伤电池的是天天满放满充。

## 四、改装分层：看动力链动了哪一段

改装不是二元变量。同样是"改过的车"，风险差 10 倍。

| 层级 | 动了什么 | 风险 | 残值 |
|---|---|---|---|
| **原装** | 没动，或只换易损件（轮胎、刹车片） | 无 | 基准 |
| **轻改** | 减震、卡钳、上泵、轮毂、包围、座垫 | 低（可复原） | ≈ 原装 |
| **中改** | 控制器 或 电机 | 中（超功率、失保） | 折价 |
| **重改** | 大单体电池（≥60V 或 48V≥40Ah），或控制器+电机双改 | **高（违法、查到就扣）** | 大幅折价 |

### 为什么「中改以上」要单独算

1. **超国标**：电自强制 48V、≤55kg、≤25km/h。换 60V 电池或大功率控制器，直接失去合法身份
2. **失保**：动过控制器，原厂保修作废
3. **不可复原**：车架开孔、线束剪接，复原成本比改装还高

### 一条实战观察

**改装在二手市场基本不溢价。** 实测 MK2 样本：

| 分层 | 中位价 |
|---|---|
| 原装·个人 | ¥6500 |
| 轻改 | ¥6500 |
| 重改 | ¥7888（含 ¥1 标价钓鱼贴，实际数据污染） |

改减震改上泵的钱，一分收不回来。**所以：买改装车不要为改装件付溢价，除非那些件你本来就打算买。**

唯一例外：里程极低的改装车，改装件本身值钱（比如 880 km 的车配倍耐力大闪电 + 布雷博卡钳 + 高端后减震，
这套件单买 1500+），这种等于"买零件送车架"。

## 五、空车价 ≠ 真实成本

锂电版空车出，是因为**电池拆卖比整车卖更值钱**。

```
空车 ¥3300 + 自购 48V30Ah 锂电 ¥1200–1800 = 落地 ¥4500–5100
```

而带电池整车可能只要 ¥4600。

**对比时一律换算成整车落地成本。** 拿空车价直接跟带电池价对比，是最常见的算错方式。

### 电池行情基准（九号 4825，珠三角实测）

14 条样本，价带 **¥298–500，中位 ¥420**。

这个数直接决定决策边界：

```
换电池成本 ¥420（含工时 ≈ ¥500）
vs
换车净成本 ¥2600（旧车抵 ¥2000 + 新车 ¥4600）
```

**车还能骑、只是电池不行 → 换电池。** 这是绝大多数情况下的正确答案。

## 六、需求密度：什么车好卖

「想要数」是最直接的市场信号，但**必须用对排序**。

| 排序方式 | 想要数含义 | 能不能用 |
|---|---|---|
| 「最新」 | 帖子刚挂出，想要数还没累积 | ❌ 无意义 |
| **「综合」**（平台推荐序） | 平台判定易成交 + 真实累积 | ✅ 唯一可用 |

用综合排序采样后，按型号聚合：

```
需求密度 = Σ想要数 ÷ 挂牌数
```

实测（全国，166 条）：

| 型号 | 每条平均想要 |
|---|---|
| Mz MIX | **75** |
| F90 | 57 |
| MMAX | 12 |
| F2z | 9 |

**需求密度高的型号 = 好卖 = 保值 = 将来出手容易。**

同时算**原装率**：Mz MIX 原装仅 22%，F90 原装 23% 但改装 53%。
**原装车在改装率高的型号里有溢价空间。**

## 七、卖家画像：比车更重要的信号

7 个真实案例，全部来自同一批 21 条样本：

| 主页特征 | 结论 |
|---|---|
| 3 台 iPhone + 手表 + 运动相机 + **散装锂电池** | 二手数码贩子。平台给他打了「标价不实」 |
| 4 年卖 9 件闲置，主动写"循环 109 次" | 真车主。价格实在 |
| 6 年卖 39 件，全是各种数码 | 流水贩子。写着"优先置换" |
| 在售 200+ 件，全是同款车 | 车商。标价基本是引流 |
| 描述里只有"带点脑子来问" | 钓鱼贴。没有信息量 |
| 「可上广州小白牌」 | 引流话术。注意不是"可过户" |
| 「公司户口」 | 需公司配合过户，链条长 |

### 两条硬规则

**规则 1：卖散装锂电池的人卖电动车 = 高危。**

一台车最值钱的是电池。有渠道拆卖电池的人，没有理由不拆。
原厂 48V30Ah 二手能卖 ¥800–1000，装一块杂牌 30Ah 只要 ¥630 —— 差价 ¥200–370，纯利。

**规则 2：「优先置换」不是卖车贴。**

翻译过来是：他要收车。标价是招牌，用来把有车的人钓进来，然后"你的车我按 X 收，补差价"。
拿旧车去置换，只会被压到地板价。

## 八、平台标签要会读

| 标签 | 谁打的 | 含义 |
|---|---|---|
| **标价不实** | **平台自动** | 按同类成交价判定虚价。标价是引流价 |
| 卖家信用极好 / 优秀 | 平台 | 交易记录好，但不代表这台车好 |
| 几乎全新 / 轻微使用痕迹 | **卖家自己选** | 无约束力 |
| 已用年限 6个月内 | 平台按激活推算 | 相对可信（如果能对上激活日期） |
| 里程 0.1–0.5万公里 | **卖家自己选区间** | 区间很宽，要问具体数 |

**「标价不实」是唯一一个平台主动打的负面标签，看到就当虚价处理。**

## 九、决策框架

```
┌─ 车还能正常骑吗？
│
├─ 能 ─┬─ 只是电池不行？
│      │   ├─ 是 → 换电池（¥400–500），别换车
│      │   └─ 否 → 继续骑，什么都不做
│      │
│      └─ 想升级 → 算清楚"净支出" = 新车价 − 旧车实际能卖的价
│                 （不是"新车价 − 旧车买入价"）
│
└─ 不能 → 直接换车
```

**净支出才是真实成本。** 一台 ¥4600 的新车，旧车能卖 ¥2000，净支出 ¥2600。
但如果旧车因为里程高、电池废，只能卖 ¥1500，那净支出就是 ¥3100。

**车况差的车，置换差价会被放大 2–3 倍。** 这是"折腾一次不划算"的真实原因 ——
不是升级幅度小，是旧车卖不出价。

---

## 十、一句话总结

> 二手电动车定价，**看电池不看年份，看卖家不看描述，算净支出不算挂牌价**。
